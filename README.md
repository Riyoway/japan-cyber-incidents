# Japan Cyber Incidents

日本国内の企業・団体に影響するサイバー攻撃、ランサムウェア、不正アクセス、情報漏えいなどの公開情報を整理したデータセットです。

> Publicly disclosed cyber incidents affecting organizations in Japan, structured with source-backed details.

## 収録内容

各事案について、公開情報から確認できる範囲で以下を整理しています。

- 組織名
- 組織規模・カテゴリ
- 業種・事業内容
- B2B / B2C / B2G / public
- 本社所在地・位置情報
- 従業員規模・上場情報
- 推定総利用者数
- 攻撃種別
- 発生・検知・公表日
- 発生・検知時刻、時間帯
- 状態
- 侵入経路
- 攻撃者・ランサムウェアグループと帰属根拠
- CVE・影響システム・影響地域
- 情報漏えいの有無
- 漏えいした情報
- 影響ユーザー数・件数
- サービス停止や業務影響
- 公式発表・報道・セキュリティ情報源
- 情報の確度

## 更新頻度

原則として、日本時間の **12:00** と **24:00（翌日 00:00）** の1日2回更新します。

## データ

| File | 内容 |
| --- | --- |
| `data/incidents.json` | 全事案の元データ |

## データの見方

公開情報に存在しない数値や事実は、推測だけで補完しません。

推定値を含む場合は、その根拠と確度をあわせて記録します。不明な項目は不明のまま保持します。

攻撃者やランサムウェアグループによる主張だけでは、被害や情報漏えいを確認済みとは扱いません。

### 攻撃主体の帰属

`incident.threat_actor` は互換性用の攻撃主体名です。帰属根拠が確認できる場合は `incident.threat_actor_attribution` に、種別・別名・確度・根拠・出典・確認日を記録します。

- `confirmed`: 被害組織、捜査機関、フォレンジック調査などの強い公開根拠で攻撃主体が結び付けられている
- `suspected`: 信頼できる分析で帰属が示されているが、確定的ではない
- `attacker_claim`: 攻撃者やリークサイトが犯行を主張しているが、独立した技術的帰属は確認されていない
- `unknown`: 調査したが、公開情報から支持できる攻撃主体を特定できない

被害組織がサイバー攻撃や情報漏えいを確認していても、攻撃者側の犯行声明だけを理由に `confirmed` へ昇格させません。また、ランサムウェアやマルウェアの名称だけから運用主体を推定しません。

## 注意事項

- 影響人数・アカウント数・レコード数は、事案ごとに単位が異なる場合があります。
- 複数事案間で同一人物が重複している可能性があります。
- 公開情報をもとにしたデータセットであり、日本国内のすべてのサイバー攻撃を網羅するものではありません。
- 詳細確認には、各レコードに記録された一次情報・報道ソースを参照してください。
